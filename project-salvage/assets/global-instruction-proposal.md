# 全局指令修改方案

方案：GP-topic-r1
状态：待批准
目标：已核实的用户级规则文件或设置入口
影响范围：写清应用与任务范围

## P01：改动名称

操作：新增／替换／删除
位置：相关标题、条款或插入点

修改前：

```text
现有准确原文；新增时写“无”。
```

修改后：

```text
建议写入的完整文案；删除时写“删除上述条款”。
```

依据：来源、事件位置、必要用户原话；说明为何适合全局。
预期影响：下次具体改变什么行为。
现有规则关系：已覆盖、冲突或需要合并的具体条款与处理。

## 审批与执行记录

用户可批准全部、指定条目、给出替代文案或拒绝。例如“批准 P01，其他不改”。
记录用户实际答复及对应方案版本，未答复时保持待批准。
执行后写目标、已修改／未变／未批准／待修订条目，删除模板提示。
